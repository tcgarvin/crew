# Freighter Mk1 — deck layout

Single deck, 32 x 18 tiles, hull class `light_freighter`, size class M (D72). East (high x) is
fore, west (low x) is aft: the deck was mirrored from its original bow-west layout by
`scripts/mirror-deck.mts`. The map below is generated by `crew content render-deck
deck.freighter_mk1`; regenerate it after any layout change.

No scenario sails Mk1 since D73 (the default is Freighter Mk2); it stays in the bundle as a
second, smaller footprint that every dock map's berth box must also fit.

Engineering is reachable two ways — via the central corridor (`engineering_corridor`) and via
the cargo hold (`engineering_cargo`) — so a single jammed door cannot isolate it. The bridge has
exactly one door (`bridge_corridor`).

The galley loop's zones (D81, D82) sit in the galley and mess: `pantry` (12,0)-(13,1), `serving`
(17,3) and (17,4) beside the stove's `use` tile (16,3), and `cleaning_locker` (17,7). The hull
contract requires all three, a serving tile beside a stove `use` position, and four mess seats.
The old `galley_counter` zone is now only the stove's own tiles, so it no longer overlaps `serving`.

Both ramps open in the south hull (`personnel_ramp` from the airlock, `cargo_ramp` from the
cargo hold), so a dock map can treat the ship's south flank as the quay (Dockside §3.2).

Off watch (D84), Mk1 hosts three activities, all in the galley and mess: debate, music and
baking. It has no lounge, gym, games table, vid screen, exercise rig, workbench, desk, book
shelf, sparring mat or viewport, so cards, board game, vids, video game, working out, sparring,
reading, tinkering and stargazing are never offered aboard. `crew content validate` lists these
as notes, not failures, because no scenario sails Mk1; a scenario on this deck would make each
one an error until the deck gains a venue for it.

Intercoms (slice 5, D94): one `machine.intercom` per compartment, eight, each against a wall with
its `panel` position on the room's floor. Mk1 has no locker zones, so no patch kits are stowed on
it. The hull bar is 100 (`hull.max`).
